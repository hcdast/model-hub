## 管理后台


<a id="admin-1"></a>

### 页面与操作约定

菜单由后端按角色权限返回，按钮按动作权限显示；后端守卫始终负责最终校验。统一使用 PageFrame 和 PageHeaderRegion：顶部标题/筛选/工具区、底部操作/分页区保持可见，中部内容滚动；弹窗标题和底部操作同样固定。

管理后台列表及弹窗表格统一按容器宽度分配列宽，不使用横向滚动。长标识、URL、标签和操作区可换行；中小容器保留主标识、状态、操作及排序/筛选列，其他字段通过“更多 → 详情”抽屉查看。窄容器使用带字段名的纵向行，排序、筛选、选择和原有展开功能仍可使用。

模型列表的批量操作位于底部，与分页同行。支持批量启用、禁用、改价、删除及单项删除；删除检查路由和未完成任务引用。批量部分失败保留失败项及原因。更新时间默认倒序，点击时间列在服务端切换升降序；筛选、分页与排序写入 URL。

<a id="admin-2"></a>

### 模型与供应商配置

- 配置导入先预览，保留既有启停、公开标识和价格；创建、立即更新、草稿发布与回滚共用契约校验。
- 模型更新只提交业务字段和预期修订号，不回传 `_id`、`create_time`、`update_time`、`revision` 等只读字段。缺价模型可禁用保存，启用前必须补齐有效价格。
- HTTP 200 中非零业务码仍作为失败处理，界面展示后端校验原因；成功提示必须与持久化结果一致。
- 供应商、路由与账号配置使用版本保护；409 保留输入并核对最新值，不自动覆盖他人修改。凭证仅写入后端，读取和审计使用掩码。
- 供应商健康页每 10 秒刷新，隐藏页面暂停并支持手动暂停。列表取当前数据库配置且已注册的供应商，已删除供应商不会因 Redis 历史状态残留而继续列出。没有样本时指标和状态变化时间显示“—”；CLOSED 表示未熔断，不等于已经实测健康。

<a id="admin-3"></a>

### 任务、资金与排障

任务支持组合筛选和长期未完成提示，详情关联账单、队列、回调与状态时间线。取消及修复入口按服务端能力开放；提交结果不明时先核对供应商，不凭 HTTP 错误自动退款。

报表统一 UTC 日期口径，汇总独立于明细分页；成本分清实际结算、价格快照和当前参考估算。CSV 区分当前页与全量筛选导出，执行掩码、公式转义和条数限制。钱包与账单写入依赖事务，见 [资金一致性](design.md#platform)。

队列使用 Bull 范围分页，分别统计等待、处理、失败和延迟；历史失败累计不等于当前阻塞。审计区分成功、失败和未知，通过 correlationId 关联操作并递归脱敏。

<a id="admin-4"></a>

### 构建与发布资源

后端构建生成 `dist/build-info.json`，进程启动时固定版本；前端记录构建 ID、提交、dirty 状态和时间。重新构建磁盘文件不代表运行进程已升级。OPS_* 外链需填写真实环境地址。

Dashboard 保留旧 hash 资源以兼容已打开会话；`npm run assets:prune` 默认只预览，保护当前 HTML 与依赖图，默认保留 30 天、最短 7 天，显式 `--apply` 才删除过期孤立文件。部署不要直接清空活动资源目录。

## 用户门户


本文维护首页、模型目录、模板发现与用户通知的入口、状态、权限及交互合同。

<a id="portal-1"></a>

### 首页与模型文档

<a id="portal-2"></a>

#### 系统能力与首页定位

门户的主要链路是「发现模型 → 阅读文档 → 调试模型 / 创建工作流 → 查看运行结果」。模型目录和文档支持匿名访问，创建和执行属于登录后的功能。模板、社区继续由顶部导航访问。

原首页把匿名访客引向空的最近工作流，并用静态模板及模拟评分、使用量作为主要内容。重构后将首页作为能力发现和创作入门入口；登录用户仍可继续最近的工作流。

<a id="portal-3"></a>

#### 内容与数据来源

| 区域 | 内容 | 数据 / 交互 |
| --- | --- | --- |
| 首屏 | 平台定位、原创创作场景主视觉、流程示意 | 开始创作复用登录提示；探索模型直接进入公共目录 |
| 能力概览 | 模型配置数、能力类型数、服务商数 | 从公共模型目录实时聚合；失败或加载中显示短横线 |
| 最近创作 | 最多三条工作流 | 仅登录后请求；包含加载、空状态和失败重试 |
| 创作场景 | 图像、视频、音频、文本四类图文卡片 | 分类筛选；进入对应能力的模型列表 |
| 模型发现 | 优先展示四种不同能力的实际配置 | 复用 `useCatalog`；文档链接携带模型、能力、服务商及配置 ID |
| 入门资源 | 工作流搭建、提示词、模型接入三篇指南 | 弹窗内直接阅读，链接到模型目录和文档；不要求登录 |
| 创作入口 | 底部行动区 | 登录后进入新建工作流；访客先提示登录 |

页面不再展示模拟评分或使用量。模型名称、描述沿用目录原文；新增首页文案支持中文、英文、日文。

<a id="portal-4"></a>

#### 资源与实现

- `portal/src/pages/Home.tsx`：内容和交互。
- `portal/src/pages/Home.css`：首页作用域样式，保留顶部导航及深色紫色主题，适配手机。
- `portal/src/i18n/home.ts`：三语言文案与指南正文。
- `portal/src/assets/home/`：五张原创 SVG 插画（场景、产品、星球、声波、文字排版），随应用打包，不依赖外部图片域名或对象存储。
- 所有插画标明为场景示意，不作为模型实际输出或可播放媒体展示。


<a id="portal-5"></a>

#### 模型目录与多语言

门户参考 MaaS Router 的目录与文档结构，新增以下免登录入口：

页面沿用原有顶部横向导航和暗色主题；模型目录使用卡片，文档使用分类侧栏、紧凑目录和分栏阅读布局。参考网站仅用于内容与功能组织。

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 模型目录 | `/models`（`/router` 跳转至此） | 搜索、厂商和能力筛选、名称排序、分页 |
| 文档索引 | `/docs` | 能力分类、模型和厂商搜索、厂商筛选、分页、快速接入 |
| 模型文档 | `/models/:encodedModelId?type=...&provider=...` | 模型说明、公开参数、cURL/Python/JSON 请求示例 |

同一模型标识可以属于多个能力或厂商，卡片、下拉选项和文档查询以 `model_id + model_type + provider` 区分。模型数据来自当前 MongoDB `model_configs`，不会复制参考网站的模型或价格。

中文、英文、日文可在导航或登录页面切换，选择保存在浏览器 `portal-language` 中。导航、模型目录、模型文档、登录提示及主要浏览操作使用翻译字典；模型介绍和参数说明保留后台配置原文。模型标识和 API 参数名不翻译。

<a id="portal-6"></a>

#### API 边界

- `GET /v1/catalog/models`：公开启用模型的展示字段。
- `GET /v1/catalog/models/detail?model_id=...&model_type=...&provider=...`：公开说明及可见参数定义。
- 公开接口只查询 `disabled != true` 的配置，白名单返回模型名称、标识、能力、厂商、介绍、字符串标签和可见参数；不返回内部路由、计费配置或 `hide: true` 参数。
- 既有 `/v1/models` 完整配置接口、任务和工作流接口继续要求认证。
- 目录和文档可免登录查看；“使用模型”提示登录，登录后进入带所选模型节点的新工作流。
- 示例使用实际任务协议：`POST /v1/tasks`，`model_id`、`input` 和 `options.featureType`；通过 `GET /v1/tasks/:taskId` 查询异步任务。

<a id="portal-7"></a>

#### 本地及 PM2 启动

`npm --prefix portal run build` 构建前端。`npm --prefix portal start` 使用 `portal/server.cjs` 托管 `dist`，同时将 `/api/*` 代理到后端的对应路径（去掉 `/api` 前缀）。默认门户端口 `7004`，后端目标 `http://127.0.0.1:7000`，可用 `PORT`、`HOST`、`PORTAL_API_TARGET` 配置。

PM2 的 `model-hub-portal` 使用相同服务器。已有 PM2 注册若仍指向 `serve`，需重建该门户进程注册，以便启动脚本更新生效。纯 `serve -s dist` 不提供 API 代理。

验证：`node --test portal/server.test.cjs`；后端 Jest 用例 `src/task/public-model-catalog.controller.spec.ts` 覆盖公开字段、匿名访问、厂商与能力选择、隐藏参数、原认证边界、文档示例和翻译字典。

<a id="portal-8"></a>

#### 文档阅读布局（2026-10-26）

参考 [fal 模型 API](https://fal.ai/models/fal-ai/flux/dev/api)、[WaveSpeed API 文档](https://wavespeed.ai/docs/docs-api)、[Replicate HTTP API](https://replicate.com/docs/reference/http/) 的导航、字段说明和代码示例组织方式。

- 索引左侧按能力导航，中间用紧凑行展示模型标识、能力与厂商，右侧提供接入步骤。每页 14 项；`q`、`category`、`vendor`、`page` 保存在 URL 中，刷新或后退可还原筛选。
- 同名模型仍按 `config_id`（或模型、能力、厂商组合）区分，详情 URL 保留 `type`、`provider`、`config`。
- 详情保留 `#docs`、`#parameters`、`#api`、`#playground`。参数支持搜索和仅必填过滤，逐字段展示默认值、范围、枚举、关联取值、媒体约束和可折叠嵌套结构。
- 配置文档中的标题、段落、列表、表格、链接及代码块以 React 节点展示，不执行原始 HTML；链接仅支持 HTTP(S)。
- API 页提供 cURL、Python、JSON 切换，代码配色、行号和复制；另有任务状态、错误说明、输出结构和模型示例。代码沿用实际任务协议与配置版本选择。
- 手机端导航折叠、列表调整列布局，代码在块内滚动；在线测试沿用原有表单与计费提示。


<a id="portal-9"></a>

### 模板发现与复制

本次实现建议中的 P0，以及场景筛选和使用说明。发现入口统一为 `/discover`；`/templates` 保留查询参数跳转到发现页，`/community` 跳转到社区来源筛选。旧的 `/workflows/new?template=<id>` 链接进入对应模板详情，不再打开空白工作流。

<a id="portal-10"></a>

#### 使用体验

- 列表直接读取已发布模板，支持关键词（用途、标签、模型 ID、作者）、来源、场景、内容类型、更新/创建时间和名称排序，以及服务端分页。
- 卡片显示作者、来源、节点数、模型数、更新时间和缩略图。没有缩略图时显示工作流占位视觉；不展示示例浏览量、点赞、评分和使用量。
- 详情展示真实配置的图片/视频/音频案例、输入输出对比、只读节点图、模型列表、必要输入、输出名称及使用说明。未配置案例时明确提示，媒体加载失败时提供占位反馈。
- 访客免登录浏览；复制时引导登录，登录后返回模板详情。用户明确点击复制后调用原有受保护接口，保留模型选择、参数、节点、连线、画布、输入输出和执行配置，创建当前账号的独立副本，然后进入编辑器。复制不会启动模型任务。
- 从详情返回发现页时保留原筛选条件；提供加载、接口错误重试、空列表、无匹配结果和失效模板状态。中文、英文和日文文案齐全，适配手机。

<a id="portal-11"></a>

#### 接口

新增无需登录的只读接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/v1/catalog/workflow-templates` | 仅已发布模板的分页摘要 |
| GET | `/v1/catalog/workflow-templates/:id` | 仅已发布模板的展示详情和只读图 |

列表参数：`search`（最长 100 字符）、`source=official/community`、`scenario`、`category`、`order=updated/newest/name`、`page`、`pageSize`（最大 48）。搜索按字面值匹配，不把关键词作为正则表达式执行。

公开响应显式选择字段，省略工作流执行参数、输入默认值、表达式、内部模型配置选择、创建者 ID 和完整 `workflowDefinition`。复制仍使用 `/v1/workflows/from-template/:templateId`，保留原有身份、所有权和创建配额检查。未发布、删除或非法 ID 的公开详情统一返回 404。

<a id="portal-12"></a>

#### 内容配置

沿用原有管理员模板创建/修改/发布接口，不向普通用户开放发布权限。新增可选元数据：

| 字段 | 含义 |
| --- | --- |
| `source` | `official` / `community`。历史模板由平台管理，默认归入官方来源；这不代表运行验证认证 |
| `scenario` | `ecommerce` / `marketing` / `character` / `video` / `audio` / `image` |
| `authorName` | 公开显示的作者名称 |
| `instructions` | 纯文本使用说明 |
| `examples` | 最多 6 组实际案例：`title`、`mediaType`、`outputUrl`，可选 `inputUrl`、`inputMediaType`、`description` |

案例媒体类型为 `image`、`video`、`audio`；素材链接必须为 HTTP(S)。输入和输出媒体类型可以不同，例如图片生成视频。缩略图 `thumbnail` 用于列表封面。模板定义通过现有工作流 DTO 进行嵌套结构校验。

提供 8 个官方入门工作流：商品场景图改造、营销视觉灵感图、原创角色概念设计、图片风格重绘、文字生成短片、商品图片转动态视频、文案转语音配音、营销文案起草。每个模板包含完整输入→模型→输出连线、创作文案、模型参数和使用说明。绑定当前环境的可用模型配置及版本；模型缺失、停用或参数契约不兼容时跳过。图片输入需要用户上传自己的素材。

初始化命令（使用与服务相同的本地/Nacos配置）：

```sh
npm run seed:templates              # 只检查，不写入
npm run seed:templates -- --apply    # 补充缺少的官方模板
```

初始化只插入固定 ID 对应的缺失模板，重复执行不会覆盖管理员修改、已取消发布的状态或其他模板。官方模板不伪造生成案例、社区作者或使用数据。来源标签显示已发布模板的实际总数；社区暂无发布内容时提供官方模板入口，并与搜索无匹配结果区分。

<a id="portal-13"></a>

#### 首次运行与计费配置

登录 JWT 用于确认工作流所有者；运行模型节点还需要当前账号有启用且未过期的 Portal API Key。模型任务使用该 Key 的内部计费标识关联钱包，不需要把明文 Key 填入编辑器或运行请求。

缺少 Key 时返回 HTTP 400、业务码 `1009`（`WORKFLOW_API_KEY_REQUIRED`），不会创建运行记录或提交模型任务。编辑器提供「管理 API Key」入口，工作流保存后跳转 `/settings/api-keys?returnTo=/workflows/<id>`；管理页可返回原工作流，不自动创建 Key 或触发重跑。管理页只接受已保存工作流的站内返回路径。

创建 Key 会保存用户填写的名称并创建零余额钱包，仍需为该钱包准备足够余额。`expiresAt` 未设置或显式为 `null` 均表示永不过期，列表、配额和工作流计费查询保持一致。停用或过期 Key 不作为运行时回退。


<a id="portal-14"></a>

### 用户通知

<a id="portal-15"></a>

#### 行为与范围

登录后点击顶栏铃铛，可查看当前用户触发的工作流成功、失败和取消通知。角标读取真实未读数量，为零时隐藏；没有数据时显示空状态。提供分页、仅看未读、单条已读、全部已读、刷新和查看工作流。支持中文、英文、日文。

本次接入的来源是实际 `workflow_runs` 完成记录，包含历史完成记录。通知列表不包含管理员系统告警、其他用户的运行、尚在运行中的工作流或独立 Playground 模型任务。管理员消息中心仍使用原有接口和权限。

客户端每 30 秒更新；打开面板、回到可见页面或窗口获得焦点时立即刷新。退出登录后取消请求并销毁列表，切换用户重新加载。请求失败显示错误与重试入口，不用零未读掩盖失败。

<a id="portal-16"></a>

#### 数据设计

从数据库已持久化的运行终态查询，不依赖进程内事件，也不需要为每次状态轮询重复插入通知。按认证用户 ID 限定 `triggerId`，只读取 `succeeded`、`failed`、`cancelled` 且有有效 `completedAt` 的记录。

`WorkflowRun.notificationReadAt` 保存已确认的完成时间，缺少或早于当前 `completedAt` 时为未读。单条和全部已读使用 MongoDB 更新管道将该字段设置为记录的 `completedAt`，重复操作幂等。运行重试后再次完成，会重新变为未读。全部已读只处理请求时已完成的本人运行，后续完成的运行保留未读。

新增索引 `{ triggerId: 1, completedAt: -1, runId: 1 }` 用于按用户和完成时间稳定分页；历史文档不需要回填。通知跟随运行记录保留，删除运行记录也会移除对应通知。删除工作流但保留运行时，通知仍在，显示工作流已删除并隐藏跳转链接。

响应仅包含运行 ID、终态、完成时间、已读标记和有访问权限的工作流名称/链接。不包含运行输入、输出、供应商错误、执行 Key、管理员通知或其他用户资料。

<a id="portal-17"></a>

#### 接口

接口均使用门户 JWT，并校验用户仍处于 active 状态。浏览器统一经 `http://localhost:7004/api/v1` 访问；内部 API 前缀为 `/v1`。

| 方法 | 浏览器路径 | 内容 |
| --- | --- | --- |
| GET | `/api/v1/notifications?page=1&pageSize=8&unreadOnly=false` | 返回 `items`、`total`、`page`、`pageSize`、`unreadCount` |
| GET | `/api/v1/notifications/unread-count` | 返回 `count` |
| PUT | `/api/v1/notifications/:runId/read` | 本人单条通知已读，返回剩余 `count` |
| PUT | `/api/v1/notifications/read-all` | 本人全部已读，返回 `modifiedCount` 和剩余 `count` |

分页大小 1–50，页码 1–100000；`unreadOnly` 只接受 `true` / `false`。拒绝额外身份参数，用户归属仅从认证上下文提取。单条 ID 使用 UUID v4，通知不存在或不属于本人均返回 404；未登录或禁用账号返回 401。

## 短剧制作


本文区分当前功能合同与目标体验；目标设计含尚未开放的能力，不作为已实现承诺。


<a id="drama-1"></a>

### 当前功能与接口

入口为 `/short-dramas`，作品页为 `/short-dramas/:id`。按已确认的 UI 实现独立短剧制作界面，保留原有专业工作流编辑器。首版按单集、竖屏、旁白短剧组织，最多 8 个角色、8 个场景、24 个镜头、180 秒；一次生成最多 12 项。

工作台顶部提供“新手制作引导”和“制作计划与预算”。根据当前故事/角色/分镜确认、已选素材、待选候选和后台任务定位下一项；导航位置不代表步骤已完成。唯一有效候选需明确选用，多个候选先预览；已有选片和正在制作的目标跳过，失败或只有过期候选的目标才进入待补做，每批最多 12 项。分阶段使用现有报价确认，不在后台自动连续调用模型。未完整提交的已确认请求优先提示检查并恢复，复用原请求标识，恢复前再次说明原报价内的消耗范围。

暂停制作引导、是否补充缺少旁白的偏好随作品保存，刷新后继续；暂停只停止向导推荐操作，已提交的后台任务仍会执行，需要在候选卡片逐项取消。取消旁白引导不会移除已选音频，缺少旁白的镜头保持静音。计划展示项目预算上限、已用、预留和剩余；尚未确认参数的后续阶段不虚报总报价。每批确认显示该批预计消耗及预留后的剩余额度，服务端继续执行原有预算校验。已有导出版本只代表历史完成，不能推定与当前草稿一致；出成片检查点仍引导核对画幅、字幕、声音并确认导出。

分镜、视频和成片页提供“角色与场景连续性”检查，按镜头展示关联参考图、已有选片、缺少参考图和设定更新提示；可定位角色/场景设定或对应镜头。检查只覆盖绑定与设定变化，不宣称自动识别人脸、服装或动作一致性。历史候选缺少参考图记录时明确提示人工核对；上传素材按自有素材检查，不伪造生成来源。

画面/视频报价显示本批实际传入和未传入的参考图名称。未指定模型时，在当前供应商的可用配置中优先尝试能接收更多关联参考图的模型；明确指定的配置保持原选择，具体模型与价格仍需确认。服务端优先使用模型声明的多图输入，按 maxItems 限制数量；单图输入仅传第一张，未传部分显式提示切换模型。没有图像输入时明确提示只用文字；未使用作品关联图但传入了手动图像输入时，单独展示其数量，不假称只用文字。工作台选定的参考图由服务端从当前作品候选解析，不能用请求参数悄悄替换；新生成候选保留报价时实际参考图快照，后续修改设定不改写该记录。画幅尺寸详情提供单镜头重做报价入口，已有选片保留，确认生成和选用新结果分别操作。

部署要求：

1. 更新并启动现有 API / WorkflowModule，Mongo、Redis、TaskService 和对象存储保持可用。此次渲染消费者与现有 workflow-node 一样注册在 WorkflowModule；API/monolith 进程运行渲染队列，不要只启动已有 model worker。渲染并发为 1，后续可拆成独立消费者模块。
2. API 进程安装包含 libx264、AAC 和 subtitles/libass 的 FFmpeg。命令默认 `ffmpeg`，可通过 `DRAMA_FFMPEG_PATH` 指定绝对路径。
3. 配置中文字体 `DRAMA_FONT_FILE`，默认尝试 Windows 微软雅黑和 Linux Noto Sans CJK。未找到 FFmpeg 时阻止 MP4 导出；未找到字体时阻止烧录字幕，允许无字幕 MP4 与 SRT。
4. 启用 textGenerate / textToImage / imageToImage / imageToVideo 或 textToVideo / tts / music 中实际具备的模型配置及积分价格。未配置能力会明确提示，不生成占位结果。角色一致性和旁白效果需用实际模型样片验收。
5. 登录账号启用 Portal API Key 并配置可用余额。预估积分沿用模型定价，最终结算沿用现有计费规则；项目支持原子预算准入和每项授权结算上限，钱包余额仍需单独满足；不代表供应商成本被封顶。
6. 上传沿用单文件 20 MB 限制，成片超过 20 MB 会提示降低清晰度或缩短片长。渲染源素材单文件上限 60 MB、累计 300 MB。来源须为公网 HTTP(S)；逐次解析并固定连接 IP，拒绝私网和本机地址，FFmpeg 只读取下载后的本地文件。

音轨规则：有已选旁白的镜头使用旁白，无旁白时使用静音，源视频音轨不参与混音；配乐按设置音量混入。字幕以镜头时长累计，尚未实现逐词对齐或自动让镜头随配音伸缩。渲染前检测旁白时长，超过镜头时长 0.3 秒以上时阻止该次合成，并提示具体镜头与时长，要求延长镜头或缩短旁白。该限制必须通过文案和样片验收管理，不能声称已支持对白口型或专业音轨编辑。

#### 发布与恢复操作


1. 数据变更为新增字段和 `drama-archive` 来源枚举，先发布兼容的 API/worker/scheduler，再开放入口；保留原数据库与素材，不执行批量覆盖。
2. 三类进程配置相同的 `DRAMA_FFMPEG_PATH`、`DRAMA_FFPROBE_PATH` 和字体。新增环境项见 `.env.example`；Windows 建议显式使用绝对路径，不能只在交互终端验证 PATH。
3. `DRAMA_CREATE_ENABLED=false` 暂停新建；`DRAMA_TEMPLATES_ENABLED=false` 隐藏并阻止创建模板项目；`DRAMA_GENERATION_ENABLED=false` 拒绝新报价和生成提交；`DRAMA_EXPORT_ENABLED=false` 暂停新合成。默认开启；更改后更新各进程环境。已有任务查询、结算、作品读取和文件下载继续保留。

5. 已有项目没有预算字段时按 0 处理，历史已结算费用仍核对计入。用户确认上限后才能继续生成；不得把未知账务当成 0 消耗。新项目默认上限 100，仍受钱包可用余额约束。

<a id="drama-4"></a>

### 目标体验与交互原则

**产品承诺是帮助没有提示词、模型和剪辑经验的用户，在清楚理解步骤与费用的情况下完成一集可修改、可导出的短剧。** 引导界面、分镜工作台和专业画布共享同一份制作数据；每次修改可追溯，每个付费动作有明确范围，用户随时离开后能够继续。

1. **首版聚焦能够兑现的制作任务。**

| 用户 | 当前困难 | 默认入口 | 首版交付 |
| --- | --- | --- | --- |
| 没有创作经验的新手 | 不知道从哪里开始、不会写提示词 | 一句话创作，或选示例改故事 | 中文、约 60 秒、9:16、旁白型单集 |
| 已有剧本的创作者 | 不会拆镜头、人物形象易变化 | 粘贴剧本，确认角色和分镜 | 可编辑镜头表、素材、成片 |
| 有制作经验的用户 | 希望控制模型、引用和参数 | 项目内高级设置/工作流 | 同项目内精细调整、逐镜头重拍 |

首版范围：2–3 角色、1–3 场景、10–15 镜头；先锁定一种经验证的视觉风格和一组生产配置。约 30 秒的试作模板可作为低成本入门，但不能宣称免费；90 秒、多人对白、口型和多集能力按验证情况逐步开放。单集时长是目标剪辑长度，生成时长由具体模型限制与实际素材决定。

第一版公开发布必须覆盖从输入到 MP4/SRT 导出的全过程。剧本工具、素材包可以提前内测，但页面名称和交付物应如实标注为阶段工具。

2. **用户看到五个制作步骤，系统在步骤内处理技术任务。**

| 步骤 | 页面要回答的问题 | 用户操作 | 系统处理 | 主要完成按钮 |
| --- | --- | --- | --- | --- |

模板选择是制作入口，不增加一个必做步骤。角色与场景管理可在第二步的“角色/场景”页签内切换；首版旁白音色只需选一次，对白开放后再给角色分配声线。步骤标题使用用户语言，模型 ID、JSON、节点和供应商不出现在默认表单。

分步逻辑、当前进度、返回已完成步骤并保留数据的设计，参考 [W3C 多页表单指南](https://www.w3.org/WAI/tutorials/forms/multi-page/)。付费提交前的范围复核借鉴 [GOV.UK 检查确认模式](https://design-system.service.gov.uk/patterns/check-answers/)，具体业务授权仍由本产品定义。

3. **信息架构将创作入口与专业能力同时保留。**

建议导航：我的作品 / 发现模板 / 高级工作流 / 模型与文档。沿用已有 Model Hub 品牌和深色界面，并提供一致的浅色适配；主流程不依赖用户理解“模型市场”。

| 路由建议 | 功能 | 身份与恢复 |
| --- | --- | --- |
| /create | 一句话创作、已有剧本、从模板开始 | 可公开看示例；输入草稿与登录回跳关联 |
| /projects | 我的作品：继续制作、已完成、归档 | 登录后显示自己的真实项目 |
| /projects/:id/episodes/:episodeId/:step | 五步引导与分镜工作台 | URL 可定位步骤；服务端校验可执行条件 |
| /projects/:id/assets | 人物、场景、声音与生成资产 | 项目归属权限；版本与使用位置 |
| /projects/:id/exports | 导出历史、下载、版本说明 | 成片绑定时间线版本与归档资产 |
| /discover?scenario=short-drama | 短剧模板发现 | 公开只读；使用时创建个人草稿 |

我的作品卡片显示封面/占位、标题、当前阶段、需要处理的事项、最近保存状态和“继续制作”。“继续制作”定位最靠前的真实阻塞项，不只按用户最后打开的页签跳转。登录过期时保留当前编辑，登录后回到同一镜头。

4. **创建入口只要求一个故事输入，其余提供已验证默认值。**

首屏主输入：“用一句话说说你想拍的故事”；占位示例：“一名快递员送错包裹，发现收件人竟是十年前的自己。”输入旁提供“用这个示例”和“我已有剧本”。风格和时长有推荐默认值，允许用户调整；集数、模型、帧率、seed、负面提示词、镜头数等进入后续适用的高级选项。

点击下一步先创建/保存草稿并复核本次脚本生成范围；若生成要计费，按钮明确显示报价后才开始。粘贴完整剧本可以直接人工整理和确认，不强迫再付费重写。导入初期先支持文本粘贴与 TXT，PDF/DOCX 解析作为后续能力；未实现的导入格式不显示可用入口。

匿名用户可以查看样片、模板和交互示例。保存到账号或第一次付费生成时登录；会话草稿采用有大小/有效期限制的本地临时保存，清楚标注“仅保存在此浏览器”，用户登录后再上传到自己的项目。上传私人媒体需要登录。明确区分浏览示例与使用模型生成，不将缓存示例冒充用户结果。

首版不把 API Key 原始错误暴露给创作者。短期引导“完成运行设置”，解释账号、积分与可计费凭证要求，继续使用现有 Portal Key 链路。若要免去手动创建 Key，需要另行实现受用户身份约束的服务端授权流程；不能仅隐藏错误或使用共享平台凭证。

5. **每一步采用同一套页面骨架，帮助用户形成稳定预期。**

桌面：顶部作品名、保存状态、帮助与积分入口；其下五步进度；主区域显示本步骤内容；右侧仅显示当前对象的可选设置；底部提供返回、当前操作的费用说明和一个主按钮。长列表允许页面滚动；底部操作区不得遮挡内容或键盘焦点。

窄屏：步骤折叠为“第 3/5 步：看分镜”，镜头列表改上下排列，预览与表单纵向展开；拖拽必须有“上移/下移”替代。手机首版支持查看、文字编辑、选片、恢复与导出；复杂时间线编辑优先桌面，但要明确提供桌面继续入口，保留当前状态。

页面始终呈现三项信息：当前要做的事、完成后的结果、本次操作是否收费。帮助放在相关字段附近，首次说明可以再次打开，不使用一遍即消失的长篇遮罩教学。

6. **故事步骤让用户编辑情节，而非学习提示词。**

默认展示故事摘要、开头/发展/转折/结尾、角色和对白。提供“更紧张一点”“缩短开场”“结尾增加悬念”等局部修改入口，同时保留直接编辑。模型修改先作为候选，用户选择替换；撤销恢复上一个已保存版本。高级区显示实际提示词及模型配置。

故事重新生成不覆盖已确认的角色与镜头：先展示影响预览，用户可以保留旧版本、只采用部分文本、或者创建新版本并更新后续阶段。自动检测超长对白和明显时长冲突，提供“缩短这段”“拆成两个镜头”，由用户确认。

剧本确认前检查字段完整性与引用。文字内容变化本身不收费；只有显式调用生成服务才进入报价流程。手工编辑后可保存并确认，避免强制 AI 依赖。

7. **角色步骤默认给一个可用方案，允许上传与局部修改。**

从剧本提取角色并显示角色卡：名字、身份、一张当前参考图、关键外貌/服装。先生成一个候选；“换一个形象”才增加新候选。用户上传图片时说明支持格式、尺寸和可见裁剪范围，校验失败指出具体问题。

确认角色时锁定被采用的参考版本；后续镜头自动引用该版本。编辑名字不必重做视频；编辑发型、服装、参考图时展示受影响镜头，选“仅保存新设定”或“更新选中镜头”。保留旧版并显示被哪些镜头使用。

场景采用相同操作逻辑，初版可以上传/生成一张稳定参考，描述空间、光线和时间。旁白音色先提供少量有样音且可用的选择，试听优先使用已授权固定样音；用户自定义台词试听若调用模型需展示费用。

音色选择先加载一页，中文标注优先，可筛选中文和搜索已加载的名称/语言；用户可继续加载或选择加载全部后完整搜索，加载过程可停止，失败保留已有结果并重试。每次窗口最多加载 100 页，达到上限仍有下一页时明确说明搜索未覆盖全部目录；不把标注语言当作实际配音语言，语言在配音设置中独立选择。官方样音不创建付费任务。

旁白页可批量制作缺少的旁白，每批最多 12 项，沿用同一音色和配音设置，提交前展示整批报价。跳过空台词、已有选片、已完成或正在制作的候选，避免反复扣费；完成后由用户明确选用各镜头唯一的候选，存在多个候选时逐镜头试听选择。制作方案中的模型选择支持按名称和供应商搜索。

“角色已确认”与“生成任务成功”是不同状态。生成一张图后不能自动替用户确认外观质量。

8. **分镜步骤先帮助看懂故事，再逐渐开放专业调整。**

每张镜头卡默认显示镜头序号、关键帧、简明画面、旁白/对白、预计使用时长和“修改”。景别、运镜、模型与引用详情折叠。提供顺序浏览、整体故事预览；静态关键帧配临时音轨的预览必须标为“分镜预览”，不能混同最终动态视频。

插入/删除/调整顺序后，维护稳定 shotId，重新核算时长与台词归属，不凭列表位置覆盖镜头。删除被时间线使用的镜头时展示影响并保留撤销入口。未生成关键帧的镜头显示操作入口，不以空白画框充当成功结果。

批量关键帧生成前展示待生成镜头数量和范围；已选关键帧默认保留。用户可以只改文字描述、只重新生成图片、上传替代素材。关键帧确认后再进入昂贵的视频阶段。

9. **视频步骤支持先试做、逐镜头修改和部分失败恢复。**

进入页面时显示待生成镜头和素材检查。“先试做一小段”是推荐次操作：选 1–3 个能代表风格的镜头，说明实际生成量与报价；用户确认风格后再生成其余镜头。是否默认推荐取决于已完成样片情况，不反复强迫老用户试做。

生成中显示真实已完成/总数，以及排队、生成、归档等可观测状态。供应商不提供百分比时不伪造平滑进度；预计时间只在有统计依据时显示区间，否则显示等待状态。允许离开页面，并在作品卡和通知中心继续查看，不擅自发送站外消息。

已完成视频自动成为当前唯一候选，可预览；首批结果支持“保留这些结果并继续”，不强迫逐个点击确认 12 次。用户随后随时更换选片。多个候选并列比较或切换，原选片始终有标记。新候选成功不自动替换用户已选版本。

部分失败：顶部显示“已完成 11 个镜头，1 个需要处理”；定位失败卡片，说明可操作原因和“重试这个镜头/换已验证配置/上传替代视频/保留素材稍后继续”。重试前重新报价，不承诺失败一定免费；其他镜头完整保留。

取消含义为停止尚未开始的任务并尝试取消支持取消的在途任务。已发送给供应商的任务可能产生费用，应在取消确认时说明。用户取消界面等待不会等于供应商已取消；后台仍跟踪任务终态和账务结算。

10. **成片步骤默认提供可用剪辑，用户再做少量调整。**

自动按镜头顺序形成可编辑时间线，旁白按真实音频时长排布，加入默认字幕与低音量配乐。预览前检查缺失媒体、超出素材时长、画幅和台词溢出；给出定位和修复入口。自动排布是候选时间线，用户可撤销，不覆盖已确认剪辑。

默认面板只提供顺序、镜头开头/结尾、字幕内容/样式、旁白音量、配乐和音量。高级面板逐步加入多轨、精确时间码和复杂转场。没有对齐时间戳时，字幕需要对齐服务或人工校正，不能直接按文字长度等分后标为同步。

当前实现：出成片步骤可免费读取已选旁白的真实解码时长；导出前再次检查，无法读取或超过镜头时长 0.3 秒以上时不提交渲染任务。可提出延长镜头的调整，采用前提示源视频不足将延长末帧；保留选片与手动字幕范围，单镜头 15 秒、单集 180 秒限制仍生效，调整后需重新确认分镜。旧草稿继续使用逐镜头字幕范围；新字幕可按句拆分，或免费读取已选旁白的真实停顿区间辅助估时。辅助估时不是 ASR 或逐字识别，界面必须明确说明，允许逐段校正开始、结束与文字，试听/预览后明确应用。未应用的字幕在本机按账号、作品和镜头暂存，不参与导出；旁白文字或音频改变后，已应用的分句字幕需重新对齐或手动确认，服务端导出也会检查。字幕段在镜头内排序、不重叠，最多 80 段；同一时间轴用于预览、SRT 和成片烧录，旧导出版本保留原字幕。可选统一旁白响度与说话时降低配乐，仅影响新导出版本，旧作品默认保持原有音量处理。

生成弹窗隐藏工作台自动填充的提示词、参考图、画幅与逐镜头时长；需要用户补充的参考图仍可编辑。确认报价逐镜头展示剪辑时长与模型实际生成时长，模型枚举不支持目标时长时选用相邻兼容时长，并明确裁剪或延长末帧。

画幅检查读取已选图片和视频的真实尺寸，并按实际旋转方向校正宽高；按精确素材 URL 缓存成功检测，失败可重试，不调用生成模型。生成前检查模型声明的画幅能力；未声明画幅控制时提示通常跟随参考图或结果未知。导出前列出实际尺寸、留边/居中裁切影响与放大倍数。镜头预览遵循相同的 contain/cover 设置，不将放大输出标为原生高清。

导出前复核版本、画幅、分辨率、字幕、音轨和费用。文件暂不可下载时给出真实渲染状态；完成后提供 MP4、SRT、素材包和“继续修改”。下载必须返回真实存在的可访问文件；修改后生成新的导出版本，已完成成片仍能下载。

11. **保存、状态和版本是新手体验的基础能力。**

| 对象 | 建议状态 | 用户可见表达 |
| --- | --- | --- |
| 文本编辑 | local_dirty / saving / saved / save_failed / conflicted | 有修改未保存 / 保存中 / 已保存 / 保存失败，请重试 / 发现另一处修改 |
| 阶段 | not_started / editing / generating / awaiting_review / approved / stale | 待开始 / 编辑中 / 制作中 / 等你确认 / 已确认 / 前面有修改，请检查 |
| 生成请求 | quoted / submitted / queued / running / succeeded / partially_failed / failed / cancelling / cancelled | 待确认 / 已提交 / 排队中 / 生成中 / 已完成 / 部分需要处理等 |
| 导出 | validating / queued / rendering / succeeded / failed | 检查素材 / 排队 / 合成中 / 可下载 / 合成失败 |

UI 状态是服务端业务状态的投影，不另建一套只能在浏览器恢复的状态机。项目的“需要处理”由镜头/阶段状态推导，避免冗余状态互相矛盾。持久化人工确认点不能通过前端跳页绕过。

输入在短暂防抖后自动保存；失焦/切步骤先提交，只有服务端确认后显示“已保存”。保存失败保留本地副本并明确“尚未同步”；关键付费提交和导出要求引用已保存版本。返回查看允许保留本地编辑，不能把保存失败变成静默丢失。

并发编辑采用 revision/ETag 乐观锁；冲突提示比较版本或复制为新草稿，禁止最后写入无提示覆盖。断网期间允许编辑文字，但暂停付费提交；恢复网络后同步并核对冲突。

12. **统一处理修改的影响，避免用户因回退而付出隐形成本。**

| 修改内容 | 默认影响 | 不自动发生的事情 |
| --- | --- | --- |
| 项目名称、角色名字 | 元数据/显示文本 | 不重生成画面 |
| 旁白文本 | 相关音频、字幕与时间线待检查 | 不直接重做所有视频 |
| 人物参考/服装 | 引用该版本的镜头提示更新 | 不删除旧参考和旧 Take |
| 镜头画面/动作 | 本镜头图片/视频候选待更新 | 不改其他镜头的选片 |
| 选用新 Take | 当前时间线引用待确认更新 | 不自动裁剪到不同长度造成台词丢失 |
| 顺序、字幕样式、BGM | 新时间线/渲染版本 | 不调用图片/视频模型 |
| 模型配置 | 仅对用户确认的后续生成生效 | 不更改进行中运行的配置 |

修改弹层给出受影响镜头、预计新增任务和费用；操作选项为“保存修改，稍后更新”“更新选中内容”“取消修改”。旧版本继续可查看；导出旧完整版本时清楚显示版本，不将新旧资产静默混成当前成片。

13. **费用确认是可操作的业务闭环。**

预算与草稿自动保存共用串行请求；保存预算期间仍能编辑标题，新修订返回后保留并继续保存这些编辑，不整页重载。真正的版本冲突仍保留编辑并要求处理。历史失败候选折叠展示；只有没有选片、可用结果或正在补做任务的失败目标才显示待补做，补做前仍展示报价，不自动重复调用模型。

费用区显示：本次生成范围、预计消耗、授权上限、已消耗与剩余额度；项目预算和钱包余额分别展示。没有有效报价时按钮显示“查看本次消耗”，获取报价后才允许确认生成。

统一过程：保存版本 → preflight → quote → 用户确认 → 原子额度/预算校验与预留 → 幂等提交 → 任务状态 → 实际用量结算。报价关联资产/项目/模型/模板版本和操作指纹，有有效期；内容变化、报价过期、余额变化时必须重新验证。点击两次或网络重试返回同一生成请求；主动重拍使用新请求。

明确授权本批任务与“每镜头候选数/最多重试次数”，默认不做无限自动重拍。队列传输重试不创建新的付费任务；模型质量重拍和供应商失败后的新请求按策略重新授权或在原授权上限内明确执行。

最大扣费承诺只有在计量上界、预留和结算截断均实现后才能展示。不能确定上界的模型先不进入新手默认路径；实际供应商账单超出用户授权的处理由平台结算规则负责，不能静默追加用户扣费。项目上限协调现有预锁机制，避免项目和任务双重扣费。

模板分 atomic/stage/project，项目模板声明阶段、输入表单、所需能力、审核点、输出契约和已验证样例。发现页只显示当前账号可用的配置；不支持的内容解释条件或隐藏，不伪装为点击可用。模板升级提示新版本，用户显式采用；不改变既有项目快照。

17. **后台、运营与支持能力和创作功能同步交付。**

运营维护：模板草稿/验证/发布/下架，生产配置与真实样片绑定，模型健康和能力验证，受影响模板列表。模板下架不删除用户项目；模型不可用时阻止新任务并给出恢复入口。

任务支持：按 projectId、episodeId、shotId、generationRequestId、taskId、renderId 关联排查；能识别用户授权、队列重试、供应商结果、归档和结算。重放事件不能产生额外付费任务。运营重试同样受授权与预算限制。

发布采用功能开关，分别控制创建入口、模板类型、生成能力、导出能力；后端同步执行权限检查。发现页与模板深链接不能绕过能力关闭。已有项目在暂停新生成时仍可查看、下载已完成文件。

18. **以真实新手任务验证设计，而不是只验证页面可点击。**

每个关键里程碑招募至少 5 位没有该工具经验的目标用户，任务为从一句话完成一个约定范围的短剧，不由主持人代替操作。首轮样本用于发现问题，不能据此宣称统计显著。招募与试用生成预算单独安排，本方案不代表已完成用户测试。

建议发布目标：至少 4/5 位测试者无需口头指导完成核心路径；能说清下一步和本次是否收费；能找到并只重做指定镜头；能退出后找回作品；能区分分镜预览与最终视频。未达到时优先修复阻塞，不以功能数量代替可用性。

行为指标：create_started、draft_saved、quote_viewed、generation_confirmed、generation_completed、stage_approved、take_selected、shot_regenerated、render_completed、export_download_started。事件带匿名/账号归属、项目、步骤、模板/配置版本、错误类别；不收集剧本全文、私有素材 URL 或凭证。下载开始与文件真实下载完成分开统计。

漏斗按创建→故事确认→角色确认→分镜确认→选片完成→导出成功分析；同时记录用户操作时间和模型等待时间，避免将供应商排队误判为交互复杂。质量指标同时看任务成功、人工选片通过和成片完成，不能只看 API 成功率。

19. **交付要求是完整状态、清楚指引与可维护实现同时成立。**

每个页面交付空态、加载、编辑、保存失败、权限不足、部分失败和恢复状态；UI 文案进入已有国际化机制；中文布局、键盘操作、焦点、移动端重排和状态播报一起验收。每个关键接口有归属校验、乐观锁、幂等和错误契约。

目标体验须按真实模型质量、完整状态和用户任务验证后开放。

### 短剧工作台与版本管理

#### 草稿与成片版本、剧本局部采用

新导出在确认时保存输出清单和来源草稿 revision，包含镜头顺序、视频/旁白选片、剪辑时长与起点、字幕、画幅、清晰度和混音设置。版本识别比较实际输出内容，改名、导航步骤、生成模型或未参与成片的参考图变化不会误标为未导出；草稿回到任意已成功导出的相同输出时显示已导出。旧成片没有清单时标明无法自动核对，不根据文件时间猜测。失败或进行中的成片不能完成第五步。重试同一个待提交导出请求时，若输出内容已变化，要求创建新请求，保留原清单。

剧本预览默认仅采用标题与故事，保留角色、镜头、选片和配乐。追加模式只追加勾选镜头，并只补入这些镜头关联的新角色/场景；同名设定沿用原版本并显示提示，不悄悄覆盖外貌。追加前检查 24 镜头、180 秒和角色/场景各 8 项上限。整体替换单独展示清除选片和配乐引用的影响。所有采用方式先展示影响并二次确认，不自动生成；确认期间草稿有其他编辑则要求重新预览。已有候选和成片继续保留，原计划仍遵循现有最近二十次草稿历史恢复范围。

#### 三轮交互优化

工作台统一使用「写故事、定角色、看分镜、做视频、出成片」五步。顶部只保留下一步建议及任务/预算、制作检查、成片版本入口，详情在侧栏展开；五步计划不再混用六项检查百分比。历史成片可独立播放与下载，不能据此认定当前草稿已通过检查。关闭引导不会关闭用户主动发起的操作。作品卡片按照实际缺项定位续作步骤，而不是停留在上次浏览的页面。

分镜与视频采用镜头列表加详情编辑，提供状态筛选、勾选范围和批量修改角色、场景、时长。缩短时长会同步收紧字幕时间，并要求重新确认分镜。补齐按钮重新计算缺项，保留已选素材，跳过制作中和等待选用的候选，每批最多十二项；生成前展示实际镜头范围、可用参考素材与报价，仍须明确确认。候选区区分可用、制作中与失败历史，支持放大及与当前素材对比，只有点击「设为当前」才替换选片，原候选继续保留。

竖图与视频的预览弹窗按视口限制内容高度，内容可滚动，确认选片按钮固定在弹窗底部。镜头生成会将「绘本漫剧」产品风格转换为绘本插画的视觉描述，图片要求单幅连续构图，视频要求连续单镜头，减少漫画分栏与文字气泡；模型结果仍需逐镜头检查，不以提示约束保证实际画质。

出成片页面集中预览、镜头时间线和属性面板，属性分为镜头剪辑、旁白配音、字幕、全片设置。点击镜头同步定位，前移/后移调整顺序并保存；点击字幕段定位视频时间，播放时高亮当前字幕。字幕未应用的编辑只用于预览，应用后才进入草稿。镜头预览用于检查画面和字幕位置，最终混音、全片衔接与导出结果以实际成片为准，不提供专业多轨实时混音。窄屏重排预览、时间线和属性面板，保持主要操作可达。

本轮验收覆盖真实项目的五步导航、检查与版本侧栏、字幕定位，及独立草稿的批量设置与镜头排序刷新恢复。没有新增付费生成，不将已有成片作为新模型质量验收。

- 我的作品：`/works`，按短剧项目、专业工作流、模板投稿切换；查询条件在 URL 中保留。旧 `/short-dramas` 和 `/workflows` 列表地址保留搜索参数并跳转到对应分类，原编辑器深链接继续有效。
- 开始创作：`/create`，默认提供短剧空白故事与示例故事，同时提供项目模板和专业工作流入口。首页「开始创作」也进入此页。
- 发现：`/discover?type=short-drama|workflow`，区分短剧项目模板和工作流模板。旧模板列表与社区链接进入工作流分类。模板详情保留返回筛选条件；清除工作流筛选不会切到短剧分类。
- 短剧模板支持匿名查看故事、角色与镜头文字，不伪装为已生成样片。使用时登录，创建个人草稿后进入五步工作台；不会自动生成或扣费。未开放、未发布、下架与失效模板不可通过深链接采用。

### 镜头高级流程

在分镜或视频步骤选中镜头，点击「高级流程」，确认画面或视频类型后保存项目，创建关联到该镜头的专业流程。复制该镜头提示词、已配置模型、可见默认参数、画幅与模型支持的已选参考素材；仍需用户在画布中检查并手动运行。关联和生成结果不复制整个短剧项目。

关联镜头的高级流程模型任务计入原短剧项目预算；每个节点提交前预留本次费用上限。预算不足时停止后续提交，已提交任务仍正常结算，进入前和关联提示中持续说明。生成暂停时后端也阻止关联流程的新运行与重试。画布保留原项目、镜头和源版本的返回入口。成功的同类型媒体节点输出可以加入原镜头候选，包含运行、节点、流程版本及定义哈希；重复导入只保留一份，原有选片不会自动替换。镜头设定已变化或被删除时拒绝导入，提示从最新镜头重新创建。返回时定位原镜头和制作步骤。

### 投稿、审核与发布

短剧和工作流的「提交为模板」先保存，再提交独立快照及名称、用途、使用步骤。短剧快照移除选片、模型绑定、参考素材和制作确认状态；工作流快照移除素材 URL、输入默认值、执行结果和凭证字段。提示词和故事文字属于拟公开内容，提交前明确告知。相同来源内容与投稿说明重复提交复用同一投稿，修改内容或说明可产生新投稿。

投稿者在「我的作品 → 模板投稿」查看待审核、已发布、未通过和已下架状态以及审核意见。管理后台工作流管理提供投稿列表、实际快照、审核发布、退回和下架；读取要求 workflow:read，审核要求 workflow:update 与管理员角色。发布的短剧模板进入短剧发现，工作流模板进入社区工作流发现。用户采用的是自己的副本，下架不删除已有作品或改变其内容。

P0 / P1 提供镜头画面与视频的高级流程分支及显式结果回传；阶段模板按下文的追加契约复用，任意工作流图仍不会自动还原成五步表单。后续 P2 的推荐和复用效果统计见下文，社区点赞与创作者分成未开放。

### 模板推荐与复用效果（P2）

发现页的短剧与工作流模板默认提供推荐排序，同时保留最新、来源及原有筛选。推荐综合独立创作者的使用、启动和成功完成记录；同一账号反复创建只计一个独立创作者，重复运行、重试和重复导出不重复计算项目完成。没有使用记录时按模板创建时间排序，没有时间的官方故事保留目录顺序。卡片显示独立创作者数及成功完成项目数，数据最多缓存一分钟。成功记录表示技术流程完成，不保证作品画质。

管理后台“工作流管理”增加“模板复用效果”，可分别查看短剧和工作流的创建副本、启动制作、成功完成、完成率与逐模板数据。短剧以成功导出成片计完成；工作流以至少一次运行成功计完成。上传自有素材不计作启动制作，短剧高级流程成功回传的候选计作已有制作活动。失败但已启动的项目保留在启动阶段，重复运行不会增加该阶段项目数。

统计覆盖当前保留且有明确模板来源的直接副本，跨模板版本汇总；归档项目继续统计，删除项目移出统计。用户自己复制作品不新增一次直接模板采用，来源不明的历史工作流不追溯猜测。完成率分母为创建副本数。新增模板详情浏览、采用点击和下载开始操作事件，单独展示近 30 天数据；仍不推算曝光转化率或下载完成率。使用状态只读取后端项目、运行和导出记录，不向浏览器开放写入成功数的接口，也不采集剧本、私有素材 URL 或凭证作为统计事件。

### 阶段模板与操作统计

短剧工作台顶部提供「阶段模板」，可搜索已公开短剧模板并选择追加角色设定或分镜结构。分镜同时追加依赖的角色和场景；已有选片、故事和设置保留，不会自动生成。每次应用前保存作品，超出 8 个角色、8 个场景、24 镜头或 180 秒时整次拒绝，并发修订要求刷新后重试。新增条目需要重新检查、确认。窗口显示最近应用的模板版本和作品修订记录。

镜头「高级流程」可选择工作流模板；不选时继续使用当前镜头。模板输入须在画布补齐，模型配置变化会在公开详情提示，模板版本复制后独立保存，下架不破坏已有流程。专业图不会自动改写为五步表单。

后台复用效果下增加「近 30 天操作漏斗」。详情浏览、采用点击统计匿名会话；报价查看、选片点击、下载开始统计全部短剧作品，每个阶段分别去重。两组不显示拼接转化率。选片点击可能尚未保存，打开或下载成片只说明开始，不证明完成。统计失败显示提示且不影响制作，制作成功继续由服务端运行/导出记录判断。
