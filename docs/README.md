## 维护约定

- 配置示例嵌入技术文档，仅含占位值；测试输入在源码 fixtures，生成产物在 Git 忽略的 output/。
- 私有配置、凭证、数据备份不放入文档目录，也不作为测试产物清理。
- `npm run sync:docs` 更新技术文档中的模块 AUTO 区域；`npm run validate:docs` 检查固定目录、本地链接和章节锚点。
